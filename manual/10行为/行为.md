# 行为

行为记录和管理工具，支持创建行为、添加打卡记录、标签管理等功能，帮助您追踪和管理日常行为习惯。

# 功能特性

- **行为管理**：创建、编辑、删除行为，支持加密/解密切换
- **加密支持**：支持对行为进行加密，保护隐私数据，包括行为名称、创建时间、更新时间、打卡记录、标签等
- **打卡记录**：记录行为发生的时间、描述和关联标签，支持修改和删除
- **标签系统**：支持全局标签和行为专属标签，标签类型有数值、是否、自身三种
- **时间轴展示**：可视化时间轴，显示打卡记录之间的时间间隔


# 关于加密
 
  - 密码仅保存在内存中，不做持久化；需要加密时由用户自行设置（可点击"生成随机密码"）；密码 1 小时后自动过期。
  - 有加密记录则第一次需要输入密码，正确与否以显示为准，应用内跳转只需要输入一次，刷新页面失效。
  - 打开加密行为的详情页会先要求输入密码，验证前不显示打卡记录；编辑加密行为也需要先输入密码。

# 创建行为

点击页面底部"添加"按钮，在弹出的模态框中：

- **活动名称**：输入行为的名称
- **加密选项为是**：
  - **加密密码**：需要自行设置（可点击"生成随机密码"生成，或用"复制密码"复制）。此密码关闭弹窗后无法再次查看，请妥善保存。
  - 如果已经有加密行为，会预填已验证的密码，并提示建议使用相同密码；没有验证过则需要自行输入密码

- 创建成功后弹窗关闭，行为列表自动刷新

# 行为列表

行为列表展示接口返回的行为（接口默认 page=1、pageSize=10，即最多前 10 条，页面暂无分页控件）：

- **行为名称**：点击可进入详情页
- **加密标识**：如果行为已加密，会在名称后显示"加密"标签
- **创建时间**：显示行为的创建时间
- **操作按钮**：
  - **修改**：可以修改行为名称和加密状态
  - **删除**：删除行为及其所有相关数据
- **展示/隐藏加密笔记**：如果存在加密行为，底部会显示"展示加密笔记"按钮
  - 未验证过密码时点击会弹出"验证密码"输入框，已在本站验证过密码则直接显示
  - 验证成功后，加密行为（名称、创建时间）会显示在列表中
  - 显示后按钮文案变为"隐藏加密笔记"，再次点击可隐藏；隐藏不会清空已验证的密码

# 修改行为

点击行为列表中的"修改"按钮，可以修改行为：

- **活动名称**：可以修改行为名称
- **是否加密**：可以切换加密状态


## 打卡记录

详情页以时间轴形式展示所有打卡记录：

- **时间轴**：左侧竖线连接所有打卡记录
- **时间节点**：每个打卡记录前有一个圆形节点，位于两个记录之间的中间位置
- **时间差显示**：节点上方显示与上一条记录的时间间隔
  - 自动选择合适的时间单位（刚刚、分钟、小时、天、月、年；不足 1 分钟显示"刚刚"）
  - 如果时间差大于等于1天且还有小时数，会同时显示天数和小时数（如"9天5小时"）
  - 时间差计算基于打卡记录的日期时间
- **打卡信息**：每条记录显示日期时间、关联标签、描述内容
  - 标签会换行显示，格式为"标签名称: 标签值"；布尔型值显示为"是/否"；"自身"类型标签只显示标签名称，不显示值
  - 加密行为的标签名称和值会被解密后显示
- **操作按钮**：可以修改或删除打卡记录

## 添加打卡记录

点击底部"打卡"按钮，在弹出的模态框中：

- **日期时间**：选择打卡的日期和时间（精确到小时）
- **标签选择**：
  - 可以多选全局标签和行为专属标签
  - 全局标签会显示 `[全局]` 前缀
  - 加密行为的标签名称会被解密后显示
- **标签值设置**：
  - **数值型标签**：输入数值（最小值为1，不能为负数）
  - **布尔型标签**：开关切换（是/否）
  - **自身标签**：不需要设置值，勾选该标签即表示发生
- **描述**：可选的文字描述
- 加密行为的描述和标签值会自动加密存储

## 管理标签

### 全局/行为专属标签

在行为列表页面点击底部"标签"按钮，可以管理全局标签：

- 全局标签可以在所有行为中使用
- 支持添加、编辑、删除标签
- 标签类型：数值、是否、自身（"自身"只记录该标签是否发生，不需要填值）
- 添加标签时：
  - **标签名称**：输入标签名称
  - **标签类型**：选择"是否""数值"或"自身"
  - **默认值**：标签管理不设置默认值；打卡时新选中的数值型标签默认值为 1，输入框最小值为 1，不能为负数

### 行为专属标签

在行为详情页底部点击"标签"按钮，可以管理该行为的专属标签，弹窗标题为"管理标签"：

- 仅在该行为中使用；行为加密时，标签名称会加密存储，全局标签名称不加密

# 修改加密密码 / 清除所有加密

在行为列表页点击"展示加密笔记"并通过密码后，底部会出现"修改密码"按钮，点击打开"修改加密密码"弹窗：

- **新密码**：输入新密码，可点击"生成随机密码"生成，或用"复制密码"复制
- **确定**：会用旧密码解密并重新加密所有加密行为（名称、创建/更新时间、打卡描述、记录标签值、行为专属标签名），成功后更新内存密码并提示"密码修改成功"
- **不设置密码（清除所有加密）**：点击后二次确认"所有已加密的行为将被解密，密码将被清除。确定继续？"，确认后所有加密行为被解密、加密字段和内存密码被清除，提示"已清除所有加密"

# 页面导航

- **返回**：行为列表页底部在 PC 端显示"返回"按钮（移动端自动隐藏），点击返回主页；行为详情页底部的"返回"按钮在所有端都显示，点击返回行为列表。
- **页面切换**：当离开行为相关页面时，会自动清空已验证的密码，保护隐私安全。
- **窗口切换**：当切换窗口或页面不可见时，如果密码已过期，也会自动清空。
