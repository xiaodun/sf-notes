在 sf-notes 里集中管理常用接口：把接口归入分组、每个分组内可切换环境前缀，记住 URL 与参数、一键发送并查看响应，适合日常联调与复现问题。

# 能做什么

- **分组与环境**：为接口建分组；每个分组可配置多个「前缀」（如 dev / prod 的 base URL），每次只启用一个，避免改来改去。
- **公共 Headers**：分组级配置，该分组下所有请求都会自动带上（如鉴权、区域等）。
- **保存 API**：记录名称、方法、路径；路径可与当前选中的前缀拼成完整地址；自动记住上次的 Query 或 Body。
- **发送与结果**：点击发送即发起真实请求；状态码与响应体会展示在右侧面板；再次打开同一条 API 会恢复上次请求与响应。
- **大响应**：正文超过约 64K 字符会外置到服务端文件，树形区改用结构快照展示：公共结构优先显示、可折叠与搜索，特别大的列表可继续按需展开；需要全文定位时用搜索——先查本地树，本地无命中时由服务端扫描文件，不必整包下载到浏览器。正文超过约 64MB 时不再生成结构快照，树形区会提示无法展示结构。
- **导出**：在「发送」旁点 **导出**（按钮在收到响应后才出现），从服务端缓存拉取**上游接口返回的响应体**（合法 JSON 存为 `.json` 且仅含解析后的数据；非 JSON 为 `.txt`）。超大正文按字节超过约 48MB 时改为流式下载 UTF-8 原文 `.txt`。
- **请求怎么发**：由本地服务代为发出，不受浏览器跨域限制；默认 300 秒超时，分组公共 Headers 会覆盖同名默认头。
- **大正文怎么存**：外置的正文存在服务端的正文文件里，列表接口只回结构快照与公共头，所以列表不会因为某条大响应变慢。
- **未分组与删除**：新建 API 时也可选「不归属分组」，它们会出现在侧栏「未分组」区；同方法 + 同路径的 API 不允许重复创建；删除分组会连同其下所有 API 与其本地缓存一起删除（有确认提示）。
- **超长正文**：正文超过约 200 万字符时不再解析成 JSON 树，直接显示格式化原文；原文超过约 300 万字符时只预览前 300 万字符，搜索退化为全文模式。
- **记住上次**：刷新或重开页面会恢复上次打开的分组 / API；搜索框可选 全部 / Key / Value，Enter 跳下一个、Shift+Enter 上一个，远程扫描结果可继续加载。

# 怎么用

1. 在首页进入 **API**。
2. **新建分组**（若还没有）：填分组名称；按需添加多个前缀，用单选框选定当前要用的环境；按需填写公共 Headers。
3. **新建 API** 或选中已有条目：填写名称、方法；若已配置分组前缀，在右侧「前缀 + 路径」一体框里选好环境，再填路径（或仍可直接填完整 `http(s)://` 地址）。
4. GET 时在 Query 区写参数；POST 时在 Body 区写 JSON，可用「格式化」整理缩进。
5. 点 **发送**，在下方查看状态与响应体；树形区域可展开折叠，搜索框先查本地树，本地无命中时自动转为服务端远程扫描（正文未外置时仅本地搜索）。
6. 发送旁点 **导出**：得到 `{名称}-response-body.json` 或 `{名称}-response-body.txt`（仅响应体）；超大正文流式下载时为 `{名称}-response-raw-body.txt`。文件名里的 `\ / : * ? " < > |` 会替换成 `_`，名称最长 80 个字符，名称为空时用 `response`。
7. 修改名称、方法、URL 会自动保存（名称回车或失焦、URL 失焦、方法即时）；Query 与 Body 不自动保存，只在点「发送」后随该次请求一起记住。也可在侧栏删除 API 或整个分组（删除分组会连同其下所有 API 一起删除）。
